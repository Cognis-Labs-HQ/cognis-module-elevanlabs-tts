# ガイド付きチュートリアル

このモジュールは `ui:tutorials` を通じて入門ガイドを自身のページに紐付けます。利用可能な初回訪問で自動開始し、ページタイトル横の疑問符 SVG から再生できます。ホストにはバージョン 1 のページ連動チュートリアル契約が必要です。

## 使用例

管理者ガイドは ElevenLabs の詳細ページから始まります。設定をクリックすると API キー、既定の音声、音声検索、テスト文、音声生成、任意の再生の分岐へ進みます。開かずに「次へ」を選ぶと分岐を飛ばします。ホストの公開モジュール対象契約を使い、他コンポーネントのポップアップ内部を調べません。登録で完了記録や認証情報は変更しません。

## 技術仕様

プロバイダーテストでは公開契約、4 言語の翻訳、利用条件、失敗時の後処理、未対応ホストバージョンの拒否を確認します。

ホスト共通の待ち行列でフローティング操作を提供します。初回は次へ・完了のみで中止やスキップはなく、再実行では最後の表示ステップより前にスキップを使えます。最初の表示ステップの後から再開始できます。内容の更新後も完了を維持します。明示的な highlightNext は説明ステップの呼吸するようなアニメーションだけを有効にし、動きを減らす設定では停止します。各段階は表示順に沿って異なる実操作を強調します。ガイドは現在の画面に結び付き、空や省略可能な状態を扱い、移動や所有者解除で後処理を行います。
