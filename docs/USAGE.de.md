# Anwendung

Erzeugen Sie mit einem eingerichteten ElevenLabs-Konto Sprachausgabe für berechtigte Cognis-Funktionen.

## Voraussetzungen

Ein Administrator benötigt einen ElevenLabs-API-Schlüssel, eine verfügbare Stimme und Netzwerkzugriff auf den Anbieter. Eine Vorschau speichert keine Einstellungen.

## Beispiele

Öffnen Sie die Moduleinstellungen als Administrator, geben Sie den Schlüssel ein und wählen Sie eine Stimme. Erzeugen und hören Sie Testaudio, speichern Sie ausdrücklich und aktivieren Sie das Modul für Verbraucher.

Die Administratoranleitung beginnt auf der ElevenLabs-Detailseite. Einstellungen öffnet einen Zweig für API-Schlüssel, Standardstimme, Stimmensuche, Testsatz, Audioerzeugung und optionale Wiedergabe. Weiter ohne geöffnete Einstellungen überspringt den Zweig. Ziele kommen aus dem öffentlichen Modulvertrag des Hosts, ohne fremdes Popup-Markup zu untersuchen. Registrierung verändert weder Tutorialabschlüsse noch Zugangsdaten.

## Erwartete Ergebnisse

Eine gültige Vorschau liefert abspielbares Audio. Allgemeine Synthese ist erst mit gespeichertem Schlüssel und Standardstimme bereit; ein fehlender oder deaktivierter Anbieter ersetzt keine hochgeladenen Aufnahmen.

## Fehlerbehebung

Prüfen Sie bei fehlgeschlagener Stimmensuche Anbieterzugriff und Zugangsdaten oder geben Sie eine bekannte Stimmen-ID ein. Nicht unterstützte Sprachen, zu langer Text und Anbieterfehler werden abgewiesen.
