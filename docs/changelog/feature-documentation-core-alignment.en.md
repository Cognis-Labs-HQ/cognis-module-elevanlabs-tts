# Documentation and Host Contracts

**Feature Branch:** feature-documentation-core-alignment

## Structured documentation

Info, Usage and Technical are complete localized document families declared by the module manifest. User introductions, practical procedures and current API/configuration contracts have separate views. Strict layout, reference and filename checks run in the standalone suite and CI. Source-file links follow the default branch; changelog labels retain concise commit references.

## Gateway diagnostics

Runtime diagnostics follow the host logging gateway and its output policy. Command reports use terminal streams, and a native-console guard checks module JavaScript, including aliases and computed access. Existing provider ownership, authorization and tutorial completion identities are preserved.

## Descriptive bindings

Syntax-tree naming validation scans JavaScript and TypeScript source, tooling, tests and fixtures without baselines or per-file exemptions. It checks runtime bindings, signature labels, private members, owned composite type names and methods. Conventional short forms remain valid as direct names such as `db`, `this.db`, `args` and LDAP `dn`. Composites expand non-unit abbreviations, including names inherited from upstream: `DatabaseExecutor`, `KeyringDatabaseExecutor`, `createDatabaseExecutor`, `baseDistinguishedName` and `registerStaticDirectory`. Opaque shorthand, numbered placeholders and consumed ignored bindings fail validation. Unused, unexported `_`, `id` and arithmetic `i`/`j`/`k` counters retain their defined roles; generic type parameters, canonical dependency/platform names and public payload keys retain their contracts. Owned API declarations, imports, exports and callers use one consistent name; naming-only aliases, including type aliases, fail validation. Regression fixtures protect the direct/composite distinction and canonical platform APIs. Localized technical manuals, contributor guidance, module versions, lockfiles and packaged hashes are synchronized. Measurement-unit tokens such as `ms`, `sec`, `px`, `rad` and `deg` stay abbreviated inside composites; timing and pixel expansions are restored to forms such as `INVITE_EXPIRY_MS`, `timeoutMs` and `widthPx`. Regression fixtures enforce the unit exception without admitting opaque neighboring words.
