# 使用例

設定済みの ElevenLabs アカウントを使い、許可された Cognis 機能向けの音声を生成できます。

## 前提条件

管理者は ElevenLabs API キー、利用可能な音声、サービスへのネットワーク接続を用意します。プレビューでは設定を保存しません。

## 使用例

管理者としてモジュールの Settings を開き、キーを入力して声を選びます。テスト音声を生成・再生し、明示的に保存してから利用する機能向けにモジュールを有効にします。

管理者ガイドは ElevenLabs の詳細ページから始まります。設定をクリックすると API キー、既定の音声、音声検索、テスト文、音声生成、任意の再生の分岐へ進みます。開かずに「次へ」を選ぶと分岐を飛ばします。ホストの公開モジュール対象契約を使い、他コンポーネントのポップアップ内部を調べません。登録で完了記録や認証情報は変更しません。

## 期待される結果

有効なプレビューで再生可能な音声が返ります。通常の音声合成はキーと既定の声を保存してから利用可能になり、未導入・無効なサービスでアップロード済み録音を置き換えません。

## 問題の解決

音声の検索に失敗した場合は接続と資格情報を確認するか、既知の音声 ID を入力します。未対応言語、過大な文章、サービス側の失敗は生成エラーとなり、架空の音声を返しません。
