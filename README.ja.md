# ElevenLabs 音声

設定済みの ElevenLabs アカウントを使い、許可された Cognis 機能向けの音声を生成できます。

## できること

管理者は音声を検索して既定の声を選び、設定保存前にテスト文の音声を確認できます。設定後は対応する機能から音声を要求できます。

## 始める前に

管理者は ElevenLabs API キー、利用可能な音声、サービスへのネットワーク接続を用意します。プレビューでは設定を保存しません。

## はじめに

管理者としてモジュールの Settings を開き、キーを入力して声を選びます。テスト音声を生成・再生し、明示的に保存してから利用する機能向けにモジュールを有効にします。

手順は[使用例](docs/USAGE.ja.md)、契約と設定は[技術情報](docs/TECHNICAL.ja.md)を参照してください。
